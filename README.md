## 🛑 Как убрать постоянную вибрацию и ошибку «Нет доступа» на часах

### Почему часы дрожат и вибрируют каждую секунду?
В мобильном приложении KDE Connect по умолчанию включен плагин пересылки уведомлений. В часах на базе Wear OS системное меню «Доступ к уведомлениям» скрыто производителем. Приложение бесконечно пытается запросить это разрешение, из-за чего система каждые несколько секунд выводит сообщение **«Нет доступа»** и активирует вибромотор часов.

### 💡 Решение в 1 клик:
Запустите файл **[`fix_watch_vibrations_and_access.bat`](fix_watch_vibrations_and_access.bat)** (или выполните команды вручную):

```bash
# 1. Выдать часам скрытое системное разрешение на чтение уведомлений:
adb shell cmd notification allow_listener org.kde.kdeconnect_tp/org.kde.kdeconnect.Plugins.NotificationsPlugin.NotificationReceiver

# 2. Выдать полный доступ к файловой системе (/sdcard/Download):
adb shell appops set org.kde.kdeconnect_tp MANAGE_EXTERNAL_STORAGE allow

# 3. Полностью заблокировать постоянную вибрацию мотора часов от KDE Connect:
adb shell cmd appops set org.kde.kdeconnect_tp VIBRATE ignore

# 4. Отключить назойливые сервисные пуши фоновой службы:
adb shell cmd notification set_notifications_enabled_for_package org.kde.kdeconnect_tp false
```
*После выполнения этих команд часы мгновенно перестанут вибрировать, всплывающие окна пропадут, а передача файлов продолжит работать на максимальной скорости!*

## ⚡ Сравнение: Bluetooth vs KDE Connect (Wi-Fi)

| Параметр | Обычный Bluetooth (Mi Fitness / Wear) | ⚡ KDE Connect (Wi-Fi) |
| :--- | :--- | :--- |
| **Скорость передачи** | ~40–80 КБ/с (очень медленно) | **15–40 МБ/с (мгновенно)** |
| **Передача музыки (альбом 100 МБ)** | ~25–35 минут (часы греются) | **3–5 секунд** |
| **Установка APK на часы** | Только через ПК или сложные утилиты | **Отправил APK со смартфона $\rightarrow$ установил** |
| **Общий буфер обмена** | ❌ Нет | **✅ Мгновенная вставка текста / ссылок** |
| **Привязка к облаку** | Требуется аккаунт Xiaomi/Samsung | **100% автономно, без интернета** |
| **Шифрование** | Зависит от производителя | **Сквозное TLS-шифрование (RSA 2048)** |

## 🛠️ Пошаговое руководство по установке

### Шаг 1. Установка на смартфон
1. Скопируйте **`kdeconnect-phone.apk`** на смартфон и установите его через проводник (либо установите из [Google Play](https://play.google.com/store/apps/details?id=org.kde.kdeconnect_tp) или [F-Droid](https://f-droid.org/packages/org.kde.kdeconnect_tp)).
2. Откройте приложение и предоставьте базовые разрешения.

---

### Шаг 2. Установка на смарт-часы (Xiaomi Watch 5 / Wear OS)

#### Способ А: С компьютера через скрипт (Рекомендуется)
1. **Включите отладку на часах**:
   * На часах перейдите в: **Настройки** → **Система** → **Об устройстве** → быстро нажмите **7 раз на «Версия сборки»**.
   * Вернитесь в **Настройки** → откройте появившееся меню **«Для разработчиков»** → включите:
     * **Отладка по ADB**
     * **Беспроводная отладка** (или *«Отладка по Wi-Fi»*).
2. На экране часов отобразится IP-адрес и порт (например: `192.168.1.45:5555`).
3. На компьютере запустите **`install_to_watch.bat`**, введите IP и порт часов и нажмите `Enter`.
4. Скрипт сам зальет APK, выдаст нужные права доступа к памяти и сразу заблокирует бесконечные вибрации.

#### Способ Б: Полностью без ПК (со смартфона через Bugjaeger)
1. Установите на телефон бесплатное приложение **Bugjaeger** из Google Play.
2. Подключите телефон и часы к одной Wi-Fi сети (или раздайте Wi-Fi с телефона).
3. Включите беспроводную отладку на часах.
4. В Bugjaeger нажмите иконку вилки 🔌, введите IP-адрес часов и нажмите **Connect** (на часах нажмите «Всегда разрешать»).
5. Перейдите во вкладку **Packages** → нажмите **`+`** → выберите **`kdeconnect-watch.apk`**. Установка выполнится за несколько секунд.
6. В Bugjaeger на вкладке **Commands** вставьте команду для отключения вибрации:
   `cmd appops set org.kde.kdeconnect_tp VIBRATE ignore`

---

### Шаг 3. Сопряжение устройств

1. **Подключение к сети**:
   * Смартфон и часы должны находиться в одной сети.
   * *Если вы не дома:* включите на смартфоне **«Точку доступа Wi-Fi»** и подключите часы к ней.
2. Запустите приложение **KDE Connect** на часах и на смартфоне.
3. В приложении на смартфоне нажмите на появившееся имя часов $\rightarrow$ **«Запросить сопряжение»** (*Request pairing*).
4. На экране часов нажмите **«Принять»** (*Accept*).

## 🚀 Практические сценарии использования

### 1. Передача музыки на часы для пробежек без телефона
1. На смартфоне выберите аудиофайлы (.mp3, .flac) в проводнике.
2. Нажмите **«Поделиться»** $\rightarrow$ выберите **KDE Connect** $\rightarrow$ выберите **Часы**.
3. За 3–5 секунд треки скопируются в папку `/sdcard/Download/` на часах.
4. Откройте любой плеер на часах (например, Sun Player или Wear Media) и слушайте музыку в беспроводных наушниках напрямую с часов!

### 2. Установка любых APK на часы прямо с телефона
1. Скачайте APK для Wear OS на смартфон.
2. Передайте его через KDE Connect на часы.
3. Откройте файл на часах через файловый менеджер (например, AnExplorer Wear) и установите без ПК.

### 3. Общий буфер обмена
* Скопируйте длинный текст, ссылку или пароль от Wi-Fi на смартфоне/ПК.
* На часах нажмите «Вставить» в любом поле ввода.

## 🔍 Тонкая настройка интерфейса под круглый экран

Если элементы списка на круглом экране часов кажутся слишком крупными, измените плотность экрана:

```bash
# Оптимальная плотность для экранов 1.4" (450x450):
adb shell wm density 280

# Вернуть стандартный масштаб системы:
adb shell wm density reset
```
