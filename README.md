## 📖 О проекте

Официальные приложения для синхронизации смарт-часов (Mi Fitness, Galaxy Wearable и др.) передают данные через узкий канал Bluetooth со скоростью всего **30–60 КБ/с**. Попытка скинуть музыкальный альбом для бега или тестовый APK превращается в ожидание десятков минут.

**KDE Connect Bridge** решает эту проблему фундаментально. Используя открытый протокол KDE Connect поверх локального Wi-Fi, вы получаете скорость **до 25–40 МБ/с** напрямую между вашим смартфоном и смарт-часами, а также общий буфер обмена и управление плеером.

```
       ┌────────────────────────────────────────────────────────┐
       │                Локальная сеть Wi-Fi                    │
       │          (Домашний роутер ИЛИ Точка доступа с телефона) │
       └──────────────┬──────────────────────────┬──────────────┘
                      │                          │
                      ▼                          ▼
           📱 Смартфон (Android)      ⌚ Смарт-часы (Wear OS)
           ┌───────────────────┐      ┌───────────────────┐
           │ kdeconnect-phone  │ ◄──► │ kdeconnect-watch  │
           └───────────────────┘      └───────────────────┘
                     ▲                          ▲
                     │     Прямой канал LAN     │
                     └──────────────────────────┘
                      Скорость: до 40 МБ/с (Wi-Fi)
```

## ⚡ Сравнение: Bluetooth vs KDE Connect (Wi-Fi)

| Параметр | Обычный Bluetooth (Mi Fitness / Wear) | ⚡ KDE Connect (Wi-Fi) |
| :--- | :--- | :--- |
| **Скорость передачи** | ~40–80 КБ/с (очень медленно) | **15–40 МБ/с (мгновенно)** |
| **Передача музыки (альбом 100 МБ)** | ~25–35 минут (часы греются) | **3–5 секунд** |
| **Установка APK на часы** | Только через ПК или муторные тулзы | **Отправил APK с телефона $\rightarrow$ установил** |
| **Общий буфер обмена** | ❌ Нет | **✅ Мгновенная вставка текста / ссылок** |
| **Привязка к облаку** | Требуется аккаунт Xiaomi/Samsung | **100% автономно, без интернета** |
| **Шифрование** | Зависит от производителя | **Сквозное TLS-шифрование (RSA 2048)** |

## 🛠️ Полная инструкция по установке

### Шаг 1. Установка на смартфон
1. Скопируйте **`kdeconnect-phone.apk`** на смартфон и откройте его через проводник (либо установите из [Google Play](https://play.google.com/store/apps/details?id=org.kde.kdeconnect_tp) или [F-Droid](https://f-droid.org/packages/org.kde.kdeconnect_tp)).
2. Откройте приложение и дайте базовые разрешения (доступ к файлам и уведомлениям).

---

### Шаг 2. Установка на смарт-часы (Xiaomi Watch 5 / Wear OS)

Выберите один из двух способов:

#### Способ А: Через компьютер (Скрипт в 1 клик)
1. **Включите отладку на часах**:
   * На часах перейдите в: **Настройки** → **Система** → **Об устройстве** → быстро нажмите **7 раз на «Версия сборки»**.
   * Появится всплывающее сообщение *«Вы стали разработчиком!»*.
   * Вернитесь в **Настройки** → откройте новый пункт **«Для разработчиков»** → включите:
     * **Отладка по ADB**
     * **Беспроводная отладка** (или *«Отладка по Wi-Fi»*).
2. На экране часов отобразится IP-адрес и порт (например: `192.168.1.45:5555`).
3. На компьютере запустите **`install_to_watch.bat`**, введите IP и порт часов и нажмите `Enter`.
4. Скрипт сам зальет APK на часы и автоматически выдаст разрешения на работу с памятью и пушами.

#### Способ Б: Полностью без ПК (со смартфона через Bugjaeger)
1. Установите на телефон приложение **Bugjaeger** (доступно в Google Play).
2. Подключите телефон и часы к одной Wi-Fi сети.
3. Включите беспроводную отладку на часах (как описано выше).
4. В Bugjaeger нажмите иконку вилки 🔌, введите IP-адрес часов и нажмите **Connect** (на часах подтвердите запрос отладки).
5. Перейдите во вкладку **Packages** → нажмите **`+`** → выберите **`kdeconnect-watch.apk`**. Установка завершится за 5 секунд.

---

### Шаг 3. Сопряжение устройств

1. **Подключение к сети**:
   * Смартфон и часы должны находиться в одной сети.
   * *Совет в дороге:* Если роутера рядом нет, просто включите на смартфоне **«Точку доступа Wi-Fi»** и подключите часы к ней!
2. Запустите приложение **KDE Connect** на часах и на смартфоне.
3. В приложении на смартфоне в списке устройств появятся ваши часы.
4. Нажмите на имя часов $\rightarrow$ **«Запросить сопряжение»** (*Request pairing*).
5. На экране часов всплывет уведомление — нажмите **«Принять»** (*Accept*).
6. Устройства сопряжены!

## 🚀 Практические сценарии использования

### 1. Передача музыки на часы для пробежек
1. На смартфоне выберите нужные аудиофайлы (.mp3, .flac) в любом плеере или проводнике.
2. Нажмите **«Поделиться»** $\rightarrow$ выберите **KDE Connect** $\rightarrow$ выберите **Часы**.
3. За 3–5 секунд треки скопируются в папку `/sdcard/Download/` на часах.
4. Любой оффлайн-плеер на часах (например, Sun Player или Wear Media) сразу увидит переданные треки.

### 2. Установка любых APK на часы прямо с телефона
1. Скачайте желаемый APK для Wear OS на смартфон.
2. Передайте его через KDE Connect на часы.
3. На часах откройте файл через любой файловый менеджер (например, AnExplorer Wear) и установите его прямо на часах без компьютера!

### 3. Общий буфер обмена
* Скопируйте длинный пароль от Wi-Fi, URL-ссылку или токен на смартфоне.
* На часах в любом текстовом поле нажмите «Вставить» — скопированный текст сразу появится на часах!

## 🔍 Тонкая настройка интерфейса под круглый экран

Поскольку официальный интерфейс изначально проектировался под смартфоны, на круглом экране часов некоторые кнопки могут выходить за край. Чтобы сделать интерфейс максимально эргономичным:

```bash
# Оптимальная плотность экрана для часов (кнопки и списки станут компактными):
adb shell wm density 280

# Если нужно вернуть стандартный масштаб системы:
adb shell wm density reset
```

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Часы и телефон не видят друг друга в списке</b></summary>

* **Изоляция клиентов**: Если вы подключены к общественному или офисному Wi-Fi роутеру, там может быть включена функция *AP Isolation* (запрет связи между устройствами). **Решение:** Включите раздачу Wi-Fi точки доступа с самого телефона и подключите часы к ней.
* **Спящий режим**: Экран часов должен быть включен во время первого сопряжения, так как Wear OS может усыплять Wi-Fi при выключенном дисплее.
</details>

<details>
<summary><b>2. Куда сохраняются полученные файлы на часах?</b></summary>

Все входящие файлы сохраняются в стандартную системную директорию `/storage/emulated/0/Download/` (папка «Загрузки»).
</details>

<details>
<summary><b>3. Как передавать файлы между часами и ПК на Windows?</b></summary>

Точно так же! Установите KDE Connect на ПК (Windows 10/11). Часы и компьютер обнаружат друг друга по локальной сети, и вы сможете перетаскивать файлы мышкой прямо на имя часов.
</details>

## 🛡️ Безопасность и конфиденциальность

* Протокол KDE Connect использует алгоритм шифрования **TLS** с уникальными 2048-битными RSA-ключами, которые генерируются локально на каждом устройстве при первом запуске.
* Никакие данные, файлы или метаданные никогда не покидают пределы вашей домашней Wi-Fi сети.
